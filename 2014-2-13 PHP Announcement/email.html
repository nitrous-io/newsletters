PHP Developers Rejoice!

Many developers asked for it, and we delivered. We are introducing PHP as our latest box template to join the ring. The template comes pre-installed with PHP5, Apache2, MySQL, Composer, and many other tools.

To get started, head over to your list of boxes and create a new box using the PHP template.

Installing with Autoparts

Want to install PHP on an existing box? You can do this as well! You can use the Autoparts package manager to quickly install PHP5, Apache2, Composer, and other tools and databases like MySQL in just seconds.

To install PHP on an existing box, read our PHP guide to help you get started.

PHP Frameworks, CMS & More

If you're looking to install other frameworks such as Laravel, Phalcon, Symfony, or Yii, follow along with the official installation documentation on each framework's website. Many of these frameworks can be installed just as they are documented, but you may need to view our PHP FAQ's for any configuration help.

Install WordPress in Seconds

We've also added WordPress support to Autoparts. With just one click, you can have a fully functioning WordPress site setup in seconds.

To install WordPress within your box, simply navigate in the IDE menu to Autoparts > Install Parts, and search for WordPress. You can preview your app by navigating to Preview > Port 3000 in the IDE menu.

Read more about setting up WordPress on our support site.
