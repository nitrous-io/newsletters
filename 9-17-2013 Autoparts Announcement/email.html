Autoparts: A Package Manager for Nitrous.IO

Today we're excited to share our new package manager that allows you to install databases, languages, and other tools on your Nitrous.IO box. If you're looking to add MySQL, MongoDB, Postgres or another service to your project on Nitrous.IO, we've got you covered.

To get started with Autoparts, create a new box and run parts search to view a list of languages, databases and other packages available. Installing packages is incredibly easy. For example, to install MySQL on your box, simply run parts install mysql in the console.

For more information on how to use Autoparts, please visit the Autoparts guide on our help site, or check out this blog post.

Open Source & Building Your Own Packages

Autoparts is completely open source to allow anyone to build their own packages to run on Nitrous.IO. Developers can submit packages, which are then diligently reviewed by our operations team to ensure their quality and security. We'll also be adding popular packages every few weeks, so be sure to follow us on twitter for updates. To learn more or request package support, please check out Autoparts on Github.

Bran Box: A New Runtime

All new boxes on Nitrous.IO will run the `Bran` stack. Bran introduces support for inotify, which is used by popular tools such as guard, fswatch, and Sass. Take a look at our upgrade guide for more information on this. You can see which box version you are running in your boxes index page on the Nitrous.IO website.
