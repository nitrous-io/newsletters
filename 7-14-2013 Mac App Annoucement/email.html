Announcing Nitrous.IO for your Mac

Web IDEs are great, but they're not for everyone. If you're a faithful user of Textmate, SublimeText, BBEdit, or one of the many powerful Mac text editors, you're in luck.

We just launched Nitrous.IO for Mac, a native application that syncs files between your Mac and your Nitrous.IO boxes, allowing you to edit code locally using your favorite Mac editor.

Local File System

Use your local file system to edit code. This means you can use your favorite code editor like Sublime Text or TextMate. Files in your Nitrous.IO folder get synced to your boxes in the cloud instantaneously.

Box Management

Manage your boxes from your Mac's menubar. Start, stop, and terminate boxes with ease. Open a shell with one click, or open the Nitrous.IO web IDE instead. Everything you need in one clean little menu.

Cloud Preview

Setup port forwarding to your box to expose services like web servers, so you can preview your application development quickly and easily. Preview your applications with a simple shortcut in the application menu.

It's free and available today!
