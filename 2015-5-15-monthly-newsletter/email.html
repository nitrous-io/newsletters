Real-time Collaboration That Just Works

We've made significant improvements to the real-time collaboration feature in Nitrous Pro. Now, collaborating on your code in real-time is easier, faster, and more stable than ever before. This feature is great for remote pair-programming, coding interviews, and teaching coding.

To get started, navigate to the "Collaborators" tab within container settings on your dashboard and add collaborators using their username or email. Next, open the same file with your collaborator and you should see her cursor in real-time just like Google Docs. Take a look at the collaboration guide to get started.

Your Code, Always in Style

Hound reviews and comments on code the moment a GitHub pull request is opened, and on every follow-up commit made to an open pull request. It’s like having an automated teammate, dedicated to style, freeing developers to focus on things humans know best, such as awareness of the domain. It is a huge expense for developers to spend time each week doing something that a cloud service can do very quickly.

Hound checks style on Ruby, JavaScript, CoffeeScript, and SCSS files, with more languages coming soon.
