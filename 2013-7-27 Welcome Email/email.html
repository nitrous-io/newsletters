Getting Started on Nitrous.IO

Setting up and accessing your development environment has never been simpler.

  • Sign In and create a new box. You can configure the box to include more memory or disk space if you have enough N2O.
  • If you need more N2O, please visit the Bonus Page.
  • Keep in mind that there are many Interpreters and Tools included in your Nitrous box that you may not know about.

Accessing Your Code

With Nitrous.IO, you can access your code from almost anywhere:

  • Online via the Web IDE
  • Connecting via SSH
  • By installing the Chrome App
  • Using your local text editor and syncing with the Mac App

Need Assistance?

The Help Center contains many guides and discussions to help you with getting setup.

Collaborate with Others

You can work with other developers on the same file in real time. When editing the same file in the IDE, you and your partner can click 'Collab Mode' in order to view each others editing.

For more information on collaborating, view our Collaboration Guide.
