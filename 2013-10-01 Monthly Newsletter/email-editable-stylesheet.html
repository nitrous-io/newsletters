Autoparts: A Package Manager for Nitrous.IO

This month we released a new package manager that allows you to install databases, languages, and other tools on your Nitrous.IO box. If you're looking to add MySQL, MongoDB, Postgres or another service to your project on Nitrous.IO, we've got you covered.

To get started with Autoparts, create a new box and run parts search to view a list of languages, databases and other packages available. Installing packages is incredibly easy. For example, to install MySQL on your box, simply run parts install mysql in the console.
