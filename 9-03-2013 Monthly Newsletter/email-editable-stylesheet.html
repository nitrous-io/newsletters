Chrome Packaged App Now Available!

We are proud to announce that Nitrous.IO is one of the first packaged apps released as a Chrome Packaged App.

What is a Chrome packaged app you say? Google has now released packaged app which allows you to run an app natively, and no longer as another tab within the browser. All you need is to have the Chrome Web Browser installed, or be using a Chromebook/Chromebook Pixel.

All Nitrous users will receive an extra 5 N2O for installing the app. So what are you waiting for?
